# 🛒 E-Commerce Store

A modern, responsive e-commerce web application built from scratch using **HTML, CSS, and JavaScript**.

This project focuses on creating a realistic shopping experience while demonstrating practical frontend development skills, including dynamic product rendering, search and filtering, shopping cart management, local storage, API integration, and responsive UI design.

## 🚀 Features

- 🛍️ Browse products
- 🔎 Search products
- 🏷️ Filter products by category
- ↕️ Sort products by price/rating
- 📦 View detailed product information
- 🛒 Add/remove products from cart
- ➕ Increase/decrease product quantity
- 💰 Automatic cart and total price calculation
- ❤️ Wishlist functionality
- 💾 Persistent cart and wishlist using `localStorage`
- 📱 Fully responsive design
- 🌙 Dark/Light mode
- 🔔 User-friendly notifications
- ⚡ Dynamic product rendering
- 🌐 API integration
- ⏳ Loading and error states
- 🧾 Checkout interface
- ✅ Form validation

## 🛠️ Technologies Used

- **HTML5** – Semantic webpage structure
- **CSS3** – Styling, Flexbox, Grid, animations, and responsive design
- **JavaScript (ES6+)** – Application logic and DOM manipulation
- **Fetch API** – Fetching product data
- **LocalStorage API** – Persisting cart and wishlist data
- **Git & GitHub** – Version control and project management
